# 0002：按任务选择 CI runner

## 背景与设计条件

公开作业需要与私有源码、凭据和缓存隔离。自建环境可承担私有作业及远程 BuildKit 构建，减少私有检查对托管作业计费的依赖。

## 决策与确认依据

公开 Linux 检查与 Web、Admin 镜像发行使用 GitHub `ubuntu-26.04`。私有 Linux 检查与发行通过 `stuhelper-arc` 组调度，组内任一可用站点均可接单。原生平台任务按 SDK 要求选择运行环境。

runner 容器使用 Ubuntu 26.04 和公开 GHCR 版本 tag。私有依赖缓存由自建服务按仓库和分支隔离，可信 develop/main 成功后可保存，PR 只恢复。GitHub 托管环境使用独立的公开仓缓存。

## 备选与取舍

全部走托管环境会使私有检查依赖组织的托管作业计费。全部自建需要同时维护公开和私有隔离池。当前分工保留托管的公开检查，将自建容量用于私有作业。

## 后果与验证

迁移保留既有检查名称。新站点先验收作业调度、缓存隔离和回退，再调整站点容量。主机维护和容器镜像更新分别执行。规则与操作分别见 [CI 规格](../spec/ci-runners.md)和 [CI 指南](../guide/ci-runners.md)。
