# 数据保留与删除

## 保存范围

数据按用途分类保存。审计、数据库、对象存储、索引与备份采用同一分类。个人信息期限以生产已发布的条款为准。[《StuHelper 用户条款与隐私说明》第 4 节](https://stuhelper.com/terms.html)

| 数据 | 默认保留与处理 |
| --- | --- |
| 账号基本资料、学校资格与必要的课程关联 | 提供相关服务期间保存。注销完成或服务目的结束后 30 日内删除不再必要的个人资料 |
| 认证材料及含个人信息的第三方原始响应 | 审核、复核或申诉结束后最多保留 90 日。学生认证原始材料沿用 30 日的常规清理期限 |
| 支撑当前资格的最小结论 | 支撑当前资格期间保存，资格失效或撤回后 30 日内清理 |
| 登录会话 | 连续 30 日无操作后失效，自登录起最长 90 日。撤销提交后立即停止使用 |
| 一般诊断日志 | 保留 30 日 |
| 已读站内通知 | 自标记已读起保留 180 日。用户主动删除立即生效 |
| 未读站内通知 | 自创建起最多保留 365 日。用户主动删除立即生效 |
| 一次性学校认证任务的密码与临时会话 | 任务内使用，任务结束销毁，最长存活 15 分钟；不用于限制另行授权的长期存储托管 |
| 学校邮箱验证码及平台投递数据 | 验证码五分钟有效。平台临时投递任务和受理回执按 24 小时规则清理，境外副本按专项告知的接收方与期限处理 |
| 学校数据认证凭据 | 本人单独授权后加密保存，供校验与重验使用。停止重验时立即删除账号、密码和明文学号。恢复备份后先执行停止重验和注销清理 |
| 历史选课授权及最少身份关联 | 停止重验后以已授权的截至学期限制读取。业务账号注销完成时删除授权、匹配关联和个人选课缓存。[学校数据认证](student-verification.md#学校数据认证) |
| 长期存储托管凭据 | 经账号拥有者明确授权，在托管授权有效期间保存；到期、撤回或替换后停止使用并清理，业务记录只保存凭据引用 |
| 存储供应商会话与续期材料 | 按供应商实际有效期和托管授权范围管理，失效后续期或重新登录；授权终止立即停用，不沿用临时学校认证的 15 分钟上限 |
| 导入临时文件 | 处理完成后 24 小时清理，已归档的业务映射保留来源标识 |
| 撤回重编草稿及整条讨论 | 撤回成功后保留 24 小时，到期永久删除正文、版本、回复和投票 |
| 已主动删除的评价讨论 | 删除成功后业务存储清除内容，检索和缓存同步失效 |
| 上传临时对象 | 24 小时内建立有效引用，过期未引用对象清理 |
| 群消息处理证据 | 默认 30 天，按获准的群消息功能配置范围 |
| 敏感字段查看、管理操作与注销审计 | 保留 12 个月，访问按独立审计权限管理 |
| 受控文件交付与授权审计 | 沿用上述审计的 12 个月期限与访问权限 |
| 运行安全日志 | 默认 6 个自然月，日志字段经过脱敏 |
| Casdoor `webhook_event` 终态投递记录 | 自进入 `Success` 或 `Failed` 起保留 6 个自然月。待投递、重试中或终结时间无法确认的记录继续保存 |
| 导出文件 | 默认 24 小时，访问同时检查操作者和原授权范围 |
| 幂等响应 | 完成后 24 小时；业务唯一键依所属业务事实保留 |
| outbox/inbox 投递详情 | 完成后 90 天；去重标识与业务唯一性按事件类型保存 |
| 订单、交易与账本记录 | 自交易完成起至少保存 3 年，履约、争议及适用法定期限仍未结束时继续保留 |
| 退款收款资料 | 自退款终结起保留 3 年。期满且无有效 `legal_hold` 时清理，订单与账本依据按各自期限处理。作为会计凭证入账的部分移交财务档案保管 |
| 已入账的退款会计凭证 | 财务档案另行保管至少 30 年，从会计年度终了后的第一天起算。平台业务库内的收款资料按上一项清理 |
| 投诉材料 | 处理期间保留必要证据，结案后保留 12 个月，仅用于复核、争议处理或履行法定义务。期满且无有效 `legal_hold` 时清理 |
| 教师主页本人申请 | 办理期间保留。按 UTC 自结案满 12 个自然月清理申请原文、待审私有头像和可还原申请内容的回执。有有效 `legal_hold` 时延期。生效的展示值、隐藏或停显决定和已批准头像按提供资料服务所需保留，管理审计沿用 12 个月 |
| 资料、目录、分类与授权 | 当前配置和仍被引用的分类及版本快照随有效业务保存，授权随履约保存。购买来源按订单和权益期限处理 |
| 资料下载包快照 | 按配置保留 1 至 60 分钟，过期停止下载并由 resources 清理 |
| 资料投诉限流窗口 | 保留 1 分钟，窗口到期可清理 |
| 资料后台任务 | 自完成起保留 24 小时。处理中或待恢复任务继续保存到处理完成 |
| 搜索投影历史与墓碑 | 当前可见投影随有效内容保存。旧修订自被替代起、最小墓碑自产生起保留 90 天。清理墓碑前确认相关订阅方已处理、无更早修订可重放且无有效保留 |
| 收藏和收藏夹 | 用户删除或注销时移除，包含名称快照和幂等响应。favorites 负责删除，以归属、并发及恢复测试验证 |
| 已注销账号投票 | 随评价讨论匿名保留并继续统计，讨论删除时一并清理；reviews 清除账号关联、回执及投票审计中的账号，以统计数量准确和不可反查测试验证 |
| 注销申请、进度及步骤 | 未完成时保存至人工处理完成，已完成或已撤销记录保留 12 个自然月；profiles 负责保留与删除，以重启恢复、当前管理员权限及幂等测试验证 |
| 主站协议和隐私政策同意凭证 | 账号存续期间保存全部版本。自注销完成起，删除明细并只保留去标识的最小签约证据 3 年。到期且无有效 `legal_hold` 时删除 |
| 学校邮箱验证码出境同意证据 | 账号存续期间保存同意和撤回证据。自注销完成起保存最小去标识证据 3 个上海日历年。到期且无有效 `legal_hold` 时清理 |
| 学校邮箱验证码出境撤回标记 | 去标识账号引用、撤回时间和并发操作标记保留 24 小时，阻止撤回前发起、尚未完成的请求写入旧确认 |
| 学校邮箱验证码出境活动 | 按北京时间保留当年及前三个完整自然年，到期批量清理活动、去重引用和年度计数 |
| 学校邮箱验证码出境影响评估及处理记录 | 运营方在内部受限环境保存至少 3 年。年度清点按自然人去重，日志和对账摘要使用脱敏信息 |
| 账号关闭标记 | 自注销完成起保留 12 个月。所属模块保存最小身份绑定和关闭事实，防止在保留期间重建账号或恢复旧数据。恢复演练检查标记仍生效 |
| 目录热度的对象日汇总 | Catalog 与 Favorites 在统计期间保留各对象按北京时间日期汇总的最新计数及墓碑，不包含账号。清理旧修订、浏览去重令牌或收藏操作事件后仍可按全部日期求和 |
| 收藏操作事件 | 保留 12 个月，favorites 负责删除，清理任务与恢复验证须核对截止时间及其他账号隔离 |
| 模块安装历史 | 随部署数据生命周期保存，平台与部署维护人负责，不能通过关闭配置删除；以重启、数据库故障和未知状态测试验证 |
| 开放平台应用及逐项授权 | 业务关系存续时保存当前审批与授权，终止后保留 12 个月审计依据。已归档应用满 12 个月且无保留依赖时，由 open-platform 分批删除应用与关联授权 |
| 开放平台授权请求及授权码哈希 | 授权请求过期 24 小时后清理，最长覆盖已签发令牌的有效期；open-platform 负责，以过期及重放测试验证 |
| 开放平台访问令牌哈希 | 到期后清理，重放时撤销对应令牌；open-platform 负责，验证有效令牌保留、过期删除及其他应用隔离 |
| 开放平台幂等响应 | 完成后 24 小时清理，业务唯一键保留；open-platform 负责，以清理上限、失败回滚和重复执行测试验证 |
| 开放平台通知和审计事件 | 保留 12 个月，第三方回报只表示声明；open-platform 负责，验证有界删除、未到期记录及清理失败恢复 |
| 开放平台日配额 | 保留当前和前一 UTC 日期，open-platform 负责，按数据库原子配额和清理测试验证 |
| 资格配置及修改审计 | 当前配置随部署保存，幂等响应 24 小时、修改审计 12 个月；platform 负责，后台有界清理到期记录，并验证修订冲突与原子持久化 |
| 媒体文件墓碑、重放与审计 | 幂等重放完成后 24 小时清理，outbox 投递详情完成后 90 天清理，审计保留 12 个月，共享内容仍有其他有效引用时，从本账号的句柄不可访问并释放起保留版本墓碑 30 天。最后一份引用释放时，从底层物理清理确认起保留 30 天；media 负责有界分批清理并跳过有效 legal_hold |
| 信息查询审计 | 默认保留 12 个自然月。information-query 由独立维护身份有界删除早于截止时间的记录，跳过逐对象登记的有效争议保留 |
| QQ 绑定及挑战 | 当前绑定按账号周期保存，解绑删除相应身份，注销删除三项；未使用挑战到期清理，已使用摘要保留 24 小时，幂等响应 24 小时，限流记录 1 天，审计和已投递事件 12 个月；未确认投递事件保留 |
| 常规备份 | 滚动保留 30 日，按类别加密和控制访问，待删除数据只用于灾难恢复 |

日志只保存必要的脱敏信息。密码、令牌与完整认证材料不进入日志。法律另有规定的按法定期限执行。

运行安全日志与 Casdoor 终态投递记录采用同一保留期，覆盖现行法律规定的网络日志最低期限。[《网络安全法》第二十三条第三项](https://www.cac.gov.cn/2025-12/29/c_1768735112911946.htm)

Casdoor 投递以终态的 `updated_time` 起算，按上海时区加 6 个自然月。目标月份没有对应日期时取当月最后一日，保留到相同本地时刻。

退款收款资料自退款终结起计算 3 年，沿用交易信息自完成之日起的最低保留期限。[《电子商务法》第三十一条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_14453aa523094819aa8f1d4530ce3cc4.html)

退款资料中作为原始凭证或记账凭证入账的部分由财务归档。财务档案按适用的到期鉴定、续留和销毁规则处置。[《会计档案管理办法》第十四至十九条及附表](https://www.mof.gov.cn/gp/xxgkml/tfs/201512/t20151214_2510365.htm)

下载包和投诉限流记录保留至对应有效窗口结束。已完成资料任务的 24 小时覆盖幂等重试窗口。搜索历史的 90 天与已确认投递详情一致，并覆盖最长 30 天的常规备份期。

旧投影的替代或隐藏时间有持久证据时沿用原截止日。缺少原时刻时，从迁移首次确认该状态起算 90 天，保留时间来源。墓碑还须确认订阅方处理完毕、旧修订无法重放且无有效保留；缺少证据时继续保存。

资料与搜索记录仍能关联个人时，适用现行个人信息保存期限。注销完成或服务目的结束后 30 日内删除不再必要的个人资料或进行不可逆匿名化。投诉材料和依法限定范围的保留适用相应期限。

注销后的最小签约证据只含去标识账号引用、文档标识、版本、摘要、同意时间和来源。凭证使用单独权限访问，仅用于相关争议、投诉和法定义务。平台参照普通诉讼时效确定该项三年保留期。[《中华人民共和国民法典》第一百八十八条](https://www.spp.gov.cn/spp/fl/202006/t20200602_463888.shtml)

长期托管可以使用获准保存的 BHpan 账号密码、专用令牌或其他存储凭据。若 BHpan 登录依赖学校统一认证密码，授权必须明确包含该密码的托管与仅用于 BHpan 重新登录，不能从一次性学校认证推定授权。

长期凭据只进入获准私有环境的秘密凭据库，加密密钥与密文分开管理。接口、业务数据库、仓库、日志与审计不返回凭据原文。撤销标记须先于任何恢复后的凭据读取生效，备份按本规格到期清理。

凭据保存期限、供应商会话寿命和验证观察窗口分别记录。15 分钟是一次性认证的项目默认值；24 小时等观察窗口是测试安排，均不代表 BHpan 声明的技术限制。

## 学校邮箱验证码出境记录

运营方按受托处理和个人信息出境事前完成个人信息保护影响评估，留存评估文档和处理记录。接收方、处理目的、范围、数量或风险发生变化时复核评估和出境路径。[《个人信息保护法》第五十五条、第五十六条](https://www.miit.gov.cn/zwgk/zcwj/flfg/art/2022/art_04a0f1fb5df244e39688fd5372623a8d.html)

账号存续期间，同意证据按账号、申请、收件身份和发布版本记录，保存文件标识、版本、摘要、服务器同意时间和首次请求标识。撤回停止后续投递，历史证据用于复核当时的授权。[学校邮箱验证码出境](student-verification.md#学校邮箱验证码出境)

注销完成后，归档移除请求标识、申请标识和收件人引用，只保留去标识账号引用、文件标识、版本、摘要、同意时间和来源，及适用的撤回、注销和到期时间。清理由认证模块按批次执行。

学校验证码按一般个人信息计数。平台按非关键信息基础设施运营者核算当年出境人数。一般个人信息出境不足十万人，无计入门槛的敏感个人信息出境，且无重要数据出境时，免办出境安全评估、标准合同及备案、个人信息保护认证。[《促进和规范数据跨境流动规定》第五条、第十条](https://www.cac.gov.cn/2024-03/22/c_1712776611775634.htm)

认证模块在出站调用前写入记录，先以北京时间确定所属年度。统计覆盖已开始的投递尝试和 Resend 结果未确定的尝试。超时重试仍纳入发生年度的统计。

验证码活动按学校和规范化学号生成分年度的去标识引用。同一学校学号跨账号、重发和重试只增加一次当年计数。未归并的收件身份数是已记录流量的保守预警上界，达到 9 万时预警，达到 10 万时再次告警。

运营核对同一处理者的全部出境场景，按自然人分别汇总一般与敏感个人信息人数，记录排除依据及类别重叠。跨校或同一人有多个学号时，仅依据获准且可核实的关联归并。缺少依据的收件身份继续各自计入预警上界。

审计和预警使用最小必要的脱敏标识或汇总数字。完整邮箱、学号、验证码和邮件正文按各自的业务期限处理，出境人数记录及诊断日志仅保留脱敏数据。已发生的处理仍计入所在年度。

运维按年使用 `verification-transfer-report` 读取学校验证码出境尝试的汇总、统计口径和告警状态。年度核对补入本功能启用前的活动，接近阈值时复核统计范围及适用路径。[认证运维指南](https://github.com/StuHelper/stuhelper-backend/blob/develop/docs/guide/verification.md)

## 删除流程

数据到期后删除或匿名化。注销后的评价与学习资料去除公开身份关联，已授予的作品许可按记录的条款继续有效。资料授权和历史版本见[资料共享](resource-sharing.md#已确认的原创授权政策)。

删除操作保存最小任务标识、对象标识、删除范围和完成状态。任务记录用于幂等清理与恢复后的再次删除，独立权限，并在常规备份保留期结束后清理无继续用途的标识。

评价删除覆盖整条讨论的正文、版本、回复和投票。关联文件取消引用，media 清理无其他业务引用的对象。外部展示、搜索和缓存立即停止返回已删除内容。清理任务每分钟执行，到期内容在清理完成前不可访问。

notifications 根据已读时间或创建时间分别清理通知，以每 24 小时计一日，达到截止时点即到期。用户可在到期前主动删除本人通知。已处理的原投递事件重复到达时遵循去重规则。[通知中心](notifications.md)

备份按既定期限整体到期，恢复流程先应用已确认删除任务和到期规则，再开放服务。删除内容的备份保留上界为 30 天。数据迁移和恢复验证包括这一步，业务切换后的新写入保留。

## 检查与例外

删除任务按有界批次和明确超时运行，监控积压、失败和最早到期时间。错误保留脱敏原因码并重试。

教师主页申请由 catalog 维护身份定期分批清理。私有照片和可还原的幂等回执随申请在同一事务清理，继续展示的内容独立保存。普通教师主页投诉沿用投诉材料规则。

获准的 catalog 迁移或治理身份通过 `catalog.register_teacher_homepage_request_hold` 登记或延期，通过 `catalog.release_teacher_homepage_request_hold` 解除。操作以申请为范围，与审计同一事务提交。

未解除且仍在有效期内的保留记录阻止自动清理。常规期限届满后，本人回执、站内通知跳转和管理 API 停止返回保留的申请材料与待审照片。需要查阅时使用独立治理授权。

因争议、执法或法定义务延长保存时，有权人员登记法律或争议保留（`legal_hold`）的依据、范围、用途、期限、结束条件和复核日期。自动清理跳过有效保留记录，保留范围内的数据使用专门访问权限。
