# 内容运营与审核

## 范围

后台内容运营包括内容审核、举报处理、隐藏与恢复、作者修改或删除申请、管理员主动编辑和反馈处理。审核与复核岗位按[管理角色配置](admin-operations.md)授权。

## moderation 模块边界

moderation 拥有审核任务、举报、复核、处置结果与授权记录。内容模块保存正文及实际可见状态，并按已批准的处理结果执行状态变化。请求包含对象、内容修订号、动作与幂等标识；处理过期版本时返回冲突并要求复核当前内容。

审核结果与 outbox 在同一事务保存，内容模块按处理结果 ID 幂等执行。任务完成状态包含处理结论和实际执行结果，未执行成功的步骤继续重试或进入人工处理。模块通信与保留期限使用公共规格。

## 工作台与处理流程

审核顺序按学校与内容类型配置。

| 内容 | 初始审核方式 |
| --- | --- |
| 普通课程评价、导师评价、追评和回复 | 默认直接发布，根据规则判断是否拦截、发布后标记复核或转为先审核 |
| 资料首次上传 | 审核通过后发布 |
| 资料新文件版本 | 审核通过后发布新版本，审核期间沿用原可用版本 |

管理员可以修改不同内容类型的审核方式，用户操作资格通过[动作资格配置](action-eligibility.md)维护。用户能区分已发布、等待审核和未获通过，并看到相应处理结果。

管理员在自己的管理范围内查看待处理内容、举报及作者申请，按内容类型、状态、学校和时间筛选，进入详情查看内容及对应申请。列表和详情显示同校同对象的其他待处理任务数。

| 事项 | 已确认业务能力 |
| --- | --- |
| 内容审核 | 查看待审内容，给出处理结果并说明结果 |
| 举报 | 查看举报对象和原因，判断是否成立并处理，向举报者反馈结果 |
| 内容隐藏与恢复 | 管理员隐藏不适宜展示的内容，符合恢复条件时恢复展示 |
| 评价修改申请 | 查看作者提出的修改，审核是否采用并向作者反馈 |
| 管理员主动编辑 | 在管理范围内主动修改内容，保留修改前后内容和管理员修改说明 |
| 评价删除申请 | 查看申请与内容，审核是否删除并向作者反馈 |
| 删除恢复 | 管理员可以恢复已删除内容，向相关用户反馈结果 |
| 匿名与署名切换 | 管理员统一切换某用户在一条讨论中的身份及全部回复，不提供用户侧切换申请入口 |
| 资料下架申请 | 查看资料、申请原因及已有购买等相关情况，按资料规则处理 |

课程评价、导师评论和回复的五分钟删除与撤回重编、24 小时草稿期限及窗口外自助追评见[评价规格](academic-content.md)。窗口之外的原帖修改与删除申请由管理员处理；追评命中待审时保留原主帖公开展示。作者按窗口直接删除和撤回超时清理均为永久删除，管理界面的恢复功能只适用于仍保留数据的管理处置。资料的下架处理与作品授权存续分别判断，见[资料规格](resource-sharing.md)。

作者可对已执行且对本人内容不利的原决定申请一次复核。复核须由另一名有权的管理员处理。管理员编辑保留原作者归属，处理记录区分作者原文、提交的更正与管理员修改。

举报者可查看本人回执及证据。被举报作者可查阅处置结果和违规分类码，回执隐藏举报者的私密理由与证据。结果生效或举报被驳回后，同校同对象不高于该内容修订的其他待审举报可联动结案，各自收到结果。

待审复核允许在原回执中追加理由与证据。每次补证递增修订，相同请求重放返回原结果。复核结束后关闭补证和重新申请入口。

## 教师主页投诉

登录用户可以针对教师主页提交站内投诉，选择现有 24 项固定分类之一并提供说明与材料，也可以联系 `legal@stuhelper.com`。投诉入口沿用现有登录、幂等、限流和材料留存规则。回执不返回投诉对象的资料。

学校管理员在现有投诉队列中筛选教师主页对象，按同校权限处理。可驳回，或通过审核结果隐藏教师主页资料及照片，目录对象、教务信息与评价继续执行既有规则。结果写入原投诉回执，并按现有流程通知投诉人。

管理客户端使用 `include_teacher_homepage=true` 将教师主页投诉纳入队列与概要，或使用对象类型 `teacher_homepage` 查看对应任务。旧客户端保持原查询范围。

教师本人申请更正、补充或隐藏走[教师资料申请](catalog-operations.md#教师本人资料申请)。投诉流程使用自己的权限、证据和回执。

## 状态与反馈

用户能够查看本人申请处于等待处理、已处理或未获通过等状态，查看管理员反馈。处理通知进入[通知中心](notifications.md)，并可返回对应内容或申请。

隐藏、恢复、删除和资料下架是不同业务结果。后台应说明将发生的变化，不能把隐藏内容表述成永久删除，也不能在操作尚未完成时显示处理成功。

## 规则、批量与认定

敏感词策略由有权管理员维护，可先试运行预览。处理前展示理由和影响，批量操作先预览并逐项显示结果。学校审核员处理本人内容时受回避规则限制，只有平台级豁免可解除对应限制。

有效评价以正常公开且满足已配置条件为准。优质内容由有权限的管理员认定，撤销认定时说明原因。奖励是否发放与追回由私有账务模块依据相应业务结果处理。

### 违规分类

举报、投诉和审核处置使用以下固定分类。选择 `other`（其他）时须填写 `reason` 说明，最多 2,000 个 Unicode 字符，去除首尾空白后须有内容。

审核队列按处置分类筛选，处置未填分类时使用提交分类。队列摘要按同一规则汇总获准学校范围内的待处理任务。有任务的分类才出现在分类汇总中，待处理总数仍计入未分类任务。

| 代码 | 中文名称 | 适用情况 |
| --- | --- | --- |
| `illegal_content` | 违法违规 | 危害国家安全、煽动颠覆、恐怖主义或极端主义等违法信息 |
| `pornography` | 色情低俗 | 色情、性暗示或低俗内容 |
| `gambling_drugs` | 赌博毒品违禁品 | 赌博、毒品、管制物品或违禁品交易 |
| `fraud` | 诈骗钓鱼 | 诈骗、钓鱼链接、虚假兼职、套取账号或钱财 |
| `violence_threat` | 暴力威胁 | 宣扬暴力、威胁人身安全、引导自残或自杀 |
| `minors_harm` | 危害未成年人 | 不利于未成年人身心健康的内容 |
| `personal_attack` | 辱骂攻击 | 辱骂、人身攻击或挑衅 |
| `harassment_discrimination` | 骚扰歧视 | 骚扰或基于地域、性别、民族、宗教等的歧视 |
| `defamation_rumor` | 诽谤谣言 | 虚构事实、诽谤他人或传播谣言 |
| `privacy_leak` | 泄露隐私 | 泄露他人姓名、联系方式、证件或住址等个人信息 |
| `impersonation` | 冒充他人 | 冒充他人、教师、学校或机构 |
| `copyright` | 侵犯著作权 | 未经许可传播教材扫描件、课件或论文等 |
| `other_ip` | 侵犯其他权益 | 侵犯商标、肖像、名誉等其他合法权益 |
| `academic_integrity` | 学术不端 | 代写、代考、作弊工具或抄袭 |
| `leaked_exam` | 泄露试题 | 泄露未公开的试题、答案或考试安排 |
| `fake_review` | 不实评价 | 非亲身经历、刷评、恶意差评或利益相关评价 |
| `wrong_teacher` | 教师或课程对应错误 | 评价或资料关联到错误的教师或课程 |
| `wrong_info` | 信息错误 | 标题、分类、标签或学期等描述与内容不符 |
| `spam` | 广告垃圾 | 广告、引流、无关推广或刷屏 |
| `malware` | 恶意文件或链接 | 病毒、木马、恶意脚本或危险链接 |
| `duplicate` | 重复内容 | 与已有内容重复 |
| `low_quality` | 内容质量低 | 无意义、灌水、无法打开或内容残缺 |
| `author_update` | 作者要求更新 | 作者本人要求更正或撤回 |
| `other` | 其他 | 以上分类未覆盖的情况，须填写说明 |

迁移时，原有九个分类码沿用同名分类。缺少分类的历史资料投诉和不在列表内的非空历史值归入 `other`，保留原有说明。其他缺少分类的记录继续视为未分类。新请求只接受表中的分类码。

| 场景 | 预期结果 |
| --- | --- |
| CM-01：作者申请修改已发布评价 | 原内容不因申请提交自动改变，管理员可查看并处理 |
| CM-02：管理员处理举报 | 能查看对象和理由，处理结果与反馈关联到原举报 |
| CM-03：内容被隐藏后符合恢复条件 | 管理员可恢复，并向相关用户反馈真实结果 |
| CM-04：作者申请下架已被购买的资料 | 能查看相关购买情况，按资料交付与退款规则处理 |
| CM-05：管理员超出本人管理范围进入内容 | 不能因为拥有某个后台角色就处理范围外内容 |
| CM-06：普通评价未命中拦截或待审规则 | 按默认设置直接发布 |
| CM-07：评价命中待审规则 | 显示等待审核，通过后再发布 |
| CM-08：上传资料或提交新文件版本 | 审核通过后发布；新版本待审期间原可用版本可用 |
| CM-09：管理员主动修改内容 | 保存修改说明，能区分修改前后内容与原作者 |
| CM-10：作者对处置提出异议 | 可申请复核，在原待审回执中补证并查看结果 |
| CM-11：管理员恢复已删除内容 | 原内容按恢复结果重新展示，保留处理记录 |
| CM-12：批量处置多个审核任务 | 先预览，最多 20 项，逐项显示保存或拒绝结果，未知结果可按原请求重试 |
| CM-13：作者查看其他用户举报的处置 | 展示处理结果和复核入口，隐藏举报者的私密证据 |
| CM-14：认定或撤销优质评价 | 检查权限及当前内容修订，保留理由、历史和审计 |
| CM-15 | 举报与投诉按账号每分钟最多 10 次新提交，重复幂等请求返回原结果，超限返回 429 且不改变任务 |
| CM-22 | 提交和处置只接受固定的分类码。选择 `other` 时，缺少说明、说明为空白或超过 2,000 个字符均被拒绝 |
| CM-23 | 既有分类按映射迁移后，按新分类筛选和汇总同一管理范围内的任务 |

## 邮件反馈

全站联系与反馈地址统一为 `feedback@stuhelper.com`。管理后台集中处理来信，不接入群推送平台。backend 使用私有凭据连接 IMAP，优先 IDLE，断线指数退避。入库后标记已读，服务器原邮件保留。

moderation 保存反馈正文、附件引用、处理状态及审计。附件存入平台存储，正文转为纯文本。系统记录 SPF、DKIM、DMARC 认证头，来源无法确认时标记发件人待核实。身份信任由独立授权判断。

查看、处理、回复分别授权，范围为全站反馈。状态包括新、处理中、已处理和垃圾。工单可认领、转交、取消认领并关联站内任务，记录当前处理人和内部备注。

SMTP 使用统一邮箱回复，发送结果未知时保留记录，同键重试不自动重发。

投诉材料结案后按 UTC 保存十二个自然月，到期删除正文、附件、回复与幂等结果。管理操作审计保存十二个月。到期仅保留防止旧邮件重复入库的脱敏摘要。程序回退保留切换后的反馈及处理记录。

| 场景 | 预期结果 |
| --- | --- |
| CM-19 | 并发重复来信只入库一次，撤销权限立即拒绝读取与下载，状态冲突不覆盖处理，审计不含私密内容 |
| CM-20 | 回复未知结果不自动重发，投诉结案满十二个月后删除材料，旧邮件不会因重新扫描复活 |
| CM-21 | 发件人超限后省略正文附件，达到总量上限暂停接收，UIDVALIDITY 改变后按内容去重 |
| CM-24：教师主页投诉 | 登录用户可按固定分类提交，学校管理员在现有队列处理，处置后按原投诉流程通知并保留回执。隐藏收回主页资料和照片，原有教师目录信息仍按规则处理 |
