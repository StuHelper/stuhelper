# 存储贡献

## 账号标识与备注

本人贡献记录、创建贡献时的存储候选项、托管绑定和有权限的管理接口返回 `account_hint`。账号事实来自托管或实例的稳定绑定，缺失时省略。公开统计只返回聚合数据。

BHpan 登录名至少五个字符时保留前两位和后两位，中间逐位替换为 `*`。不足五个字符时只保留末位，前面至少加一个 `*`。已有贡献按当前绑定读出提示。

创建和 `configure` 可提交 `display_label`。原始值最多 256 个 UTF-8 字节，去掉控制字符并去除首尾空白后最多 32 个 Unicode 字符。备注只随本人贡献响应返回。

`configure` 传空字符串清除备注，省略字段则保留。仅更新备注时可省略 `conditions`，保留现有额度、个人保留空间和到期时间。

## 范围

用户自愿贡献已接入的存储容量，供 StuHelper 各业务按保护策略使用。用户可在个人中心查看和管理本人贡献。贡献生命周期由独立模块处理，Web 和管理后台根据服务端能力与当前权限提供入口。

首期实际候选为 BHpan，贡献模型同样适用于通过验证的 S3、COS 等后端。协议、平台或用户来源、允许承载分类三个维度独立。当前不考虑整个 BHpan 服务故障，不要求跨服务商副本，见[放置与恢复](storage-placement.md)。

## 用户流程

只开放已经实际接入的服务商。贡献容量、个人保留空间、最短期限与退出处理期限由后台配置。用户选择支持的存储方式，完成所需授权，设置贡献容量、个人保留空间和贡献期限。贡献面板展示贡献量、实际占用、期限和当前是否可用。

用户可以续期、在授权失效后重新授权、暂停贡献或申请退出。暂停或退出后停止接收新文件，平台迁走既有文件后才确认退出完成。外部授权失效或容量不足时明确告知，不继续计入实际可用容量。

退出完成且已用空间、预占空间和剩余副本都为零时，历史记录释放活跃名额。用户在已退出记录中选择“重新启用”，确认当前条款和新的容量、保留空间与截止时间。贡献服务沿用原 ID，存储服务核验当前授权和控制修订后恢复写入。

请求先保存为 pending，desired_state 表示请求目标，applied_revision 表示存储端已确认修订。用户同意期限由存储核心检查，后台未运行时也会停止新写入。退出仅在副本记录、占用和预留全部归零后完成，撤权但未清理时保留明确原因。

首期 API 绑定预先验证的暂停空闲实例，不接收供应商密码或会话。条款版本、摘要、期限与容量由配置给出。公开统计使用有效观测计算可用量，过期或授权失效的容量不计入可用量。接口及当前限制见[实施状态](../development/storage-module.md)。

本人候选列表由已验证身份确定，只包含预先授权、暂停、无占用且未绑定的实例。查询不登录或探测供应商。面板明确区分请求目标和处理状态；网络结果不明时保留原请求与幂等键，权限撤销后清空私有数据。

## 网盘容量与申报上限

账号接入后，本人可在候选列表中查看网盘的总空间、已用空间、剩余空间和最近一次成功读取额度的时间。本人贡献列表和详情也提供这组数据。运营接口、公开统计、审计和日志均不返回个人网盘容量。

三个空间值按字节返回。当前样本可用时，剩余空间为总空间减去已用空间，最低为零。尚无读数、最近一次读取失败或样本过期时，三个值均为 `null`。时间取自最后一次有记录的成功读取，缺少记录时为 `null`。

表单初始可申报上限为网盘剩余空间减去该实例的安全余量，最低为零。用户填写个人保留空间后，再从初始上限扣除该值，最低仍为零。BHpan 自助接入实例的安全余量默认为 0 B，已经配置的实例使用各自的值。

服务端同时校验贡献政策和网盘上限。申报超过网盘上限时返回 `limit_exceeds_provider_capacity`，无法核实当前额度时返回 `provider_capacity_unavailable`。平台实际可用贡献量还受申报额度、占用和预占约束。

## 运营管理

管理员使用独立读取和重试权限，查看脱敏状态及迁移进度。重试只恢复用户原请求，不能扩大额度、期限或同意范围。后台维护身份不能获得管理权限。

## 首次接入与重新授权

账号托管由通用存储服务负责。用户明确授权用途与截止时间，首次接入后登记暂停实例，再单独选择贡献容量。BHpan 统一认证模式需说明学校密码仅用于 BHpan 重登；密码通过同源接口提交并加密保存。

更新使用独立客户端验证原账号和专用根，成功后按候选修订切换凭据。错误密码保留旧凭据与会话；撤销会阻止此前开始、随后返回的核验结果生效。原专用根、副本、贡献条件和密级准入不受该操作影响。

浏览器提交后清空凭据，响应不明只保留原申请标识。管理员仅能查看脱敏状态并恢复原申请，不能读取密码、替用户同意或扩大授权。申请状态与审计归存储模块，奖励和课程业务不参与凭据管理。

## 社区体验

贡献榜、奖励计算及贡献到账务的接入明确延期，不作为首期贡献功能的依赖。未来贡献榜只展示主动选择上榜者的昵称、头像和贡献统计，不公开存储账号。

增加存储贡献透明度页面，展示平台整体贡献容量、使用情况、可用容量、服务状态和更新时间。统计应区分用户申报的容量与平台实际可用的容量。公开指标为申报容量、实际可用容量、使用量、服务状态和更新时间。

当前贡献不产生积分。未来奖励由私有账务按独立规则消费获授权的核验统计，不按宣称容量直接发奖。贡献统计及生命周期不依赖奖励模块，也不因奖励关闭而停止账号接入或容量使用。

普通贡献默认仅承载可公开分发文件。获授权管理员可按贡献者账号、存储准入角色或分组配置许可，并可限定具体实例。存储准入角色和分组用于本模块的授权范围，可独立于其他模块管理。

规则按实例限定和主体类型选择。实例限定规则优先，同层贡献者规则优先于角色和分组。同层多条角色或分组规则取交集。空许可表示关闭该范围。实例要同时具备对应级别、范围和有效期内的账号授权。

待审或隔离资料需要可核验的明文保管授权。付费受限等级可配置，实际写入要求应用层加密、独立密钥和可验证恢复。收窄授权后，当前不合规副本退出读取、健康计数与发布判断，并进入修复或清理。

准入修改以修订号防止并发覆盖。系统在同一事务记录管理员、目标、结果与生效版本。贡献者的原同意与凭据独立保存。现有自有用途实例转为贡献须有记录在案的拥有者同意，沿用账号、专用目录、凭据与副本。

已单独批准的转归保留实例原额度至本次授权截止。普通新增贡献和到期续期仍使用通用额度上限。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| ST-01：用户设置贡献量和保留空间 | 接入后、填表时及本人的贡献记录可查看网盘容量。设置保留空间后校验申报上限，额度不可用时返回具体原因 |
| ST-02：贡献即将到期或授权失效 | 显示状态，提供续期或重新授权入口 |
| ST-03：用户暂停或申请退出 | 可查看排空进度。退出完成后释放名额，重新同意条款后沿用原 ID 启用 |
| ST-04：平台展示贡献容量 | 区分申报容量与实际可用情况 |
| ST-05：用户查看透明度页面 | 能看到统计范围、整体状态和更新时间 |
| ST-06：接入另一种已验证 adapter | 沿用贡献生命周期和存储准入，不修改课程资料业务 |
| ST-07：关闭奖励或贡献扩展 | 关闭奖励仍可贡献，关闭贡献仍可使用平台实例与通用文件能力 |
| ST-08：浏览器遇到未知结果或权限撤销 | 重试原请求遵循幂等约束键，权限撤销清空私有内容 |
| ST-09：管理员处理阻塞贡献 | 读取和重试分别授权，原用户条件不受该操作影响 |
| ST-10：用户接入或更新存储账号 | 明确同意，提交后清空凭据，未知结果核对原申请，沿用原绑定与贡献条件 |
| ST-11：管理员恢复托管申请 | 只恢复原同意与修订，不接收凭据，未登录或撤权立即清空私有内容 |
| ST-12：管理员配置主体、实例和级别 | 普通贡献默认只承载公开级别。规则更新和并发冲突均执行权限校验，成功变更有审计 |
| ST-13：获准将现有实例登记为贡献 | 归属和容量进入本人及公开统计，保留供应商身份、目录、凭据修订、占用及副本 |

## 配置与后续事项

同意、条件管理、暂停、续期、退出、撤权和汇总 API 已实现，七组模块场景及真实 BHpan 直接接口联调通过。贡献面板、托管入口及管理员恢复页面已实现，页面身份由宿主应用提供。上榜、奖励及账务接入延期。

服务商按实际接入能力开放，容量与期限由后台配置；文件访问权由所属业务规则，不能由实例来源或贡献奖励改变。课程资料的具体规则见[资料规格](resource-sharing.md)。

首期使用获准托管凭据重登及有效会话复用，无密码续期仅为后续可选优化。实际入口仍需验证当前授权、凭据变更、撤权和清理，不能以底层登录成功代替用户流程验收。三副本目标、两份发布门槛及已有证据见[实施准备](../development/storage-module.md)。
