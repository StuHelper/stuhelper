# 通知中心

## 范围

通知中心通过站内消息向用户展示互动、安全、账号和业务处理结果。来源模块写入待发送事件，backend 按模块协议投递，notifications 保存本人通知和已读状态。

## 站内通知与操作

| 来源 | 通知内容 |
| --- | --- |
| 内容互动 | 本人内容收到回复、点赞等互动 |
| 内容管理 | 内容处理结果、资料下架申请及教师主页资料申请处理结果 |
| 举报 | 本人举报的处理结果 |
| 认证 | 学生认证或实名核验结果，学生认证撤销、删除申请处理结果 |
| 系统 | 与用户有关的系统通知 |

Web 消息中心按互动、审核、认证和系统消息组织列表。用户可查看未读数、将单条或全部通知标记已读，并打开可访问的关联内容、申请或结果。失效或暂不可用的目标显示当前状态。

列表、未读统计和批量标记已读使用同一份标题目录，包含教师主页申请的审批结果。列表支持按分箱、通知类型和未读状态分页。未读统计返回总数以及各分箱、各类型的数量。批量标记已读可按分箱或类型筛选。

用户可删除本人的单条通知。删除保留投递去重记录，重复消费原事件不会重新生成已删除的通知。

教师主页资料申请获批或被拒绝时，向原申请账号发送业务通知。通知只提供处理结果和申请编号。打开回执时重新核对申请账号、当前有效教师认证与目录教师归属。

用户可分别设置回复与点赞通知，两项偏好默认开启。只更新其中一项时，另一项保留原值。业务处理、安全和账号通知不受互动偏好影响。聚合通知按最近一次发生时间排序，此时间随窗口内新互动更新。

已读通知从标记已读起保留 180 日，未读通知从创建起最多保留 365 日，用户主动删除优先。新互动更新聚合通知的排序时间，未读期限仍从创建起算。聚合窗口由部署配置。[数据保留与删除](data-retention.md)

到期通知从列表和未读数中移除。单条标记已读返回 `404`，批量标记跳过到期项。用户仍可主动删除尚未被任务清理的本人通知。

QQ 群内提醒由[群服务](qq-group-services.md)处理。

导航铃铛、首页和消息中心共享未读数。并发读取复用同一请求，一分钟内复用已知结果。标记已读或全部已读后的状态优先于较早请求，读取失败保留已知值，未知值不显示数字。

通知列表在读取时按当前权限解析内容名称。支持名称的目标通过 `title_params.content_name` 和 `content_name_state` 表达可读名称、内容不可访问或名称暂不可用。名称不写入通知持久数据。

对可访问的评论，解析到所属根评价时返回 `title_params.context_id`，供客户端打开讨论。支持原因码的标题在来源提供原因时返回 `title_params.reason_code`。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| NT-01：用户收到回复通知 | 列表展示通知，点击进入对应内容 |
| NT-02：用户标记一条或全部已读 | 对应未读状态和未读数更新 |
| NT-03：申请已被管理员处理 | 用户能看到结果并进入相关申请 |
| NT-04：通知关联内容已下架 | 告知内容当前不可用，不误报加载成功但无内容 |
| NT-05：未登录或偏好输入无效 | 拒绝请求，不修改通知偏好 |
| NT-06：通知写入失败或达到保留边界 | 事务失败回滚，聚合区分目标、参数与接收人。达到各自截止时间的已读和未读通知由任务有界分批清理，并发与重试按同一规则处理。用户主动删除立即生效 |
| NT-07：通知标题与参数 | 使用服务端封闭标题目录，拒绝无效标题与参数，互动计数来自聚合结果 |
| NT-08：重复事件与旧修订 | inbox 去重并返回原结果，旧修订不覆盖新状态，失败回滚聚合与修订 |
| NT-09：一个事件包含多个收件人 | 去重并逐人应用偏好，全部通知、inbox 与修订同事务写入，失败全部回滚 |
| NOTIFY-BELL-01：共享未读数与并发更新 | 页面共用当前数值，单条或全部标记已读后保持更新结果，读取失败保留已知值 |
| NOTIFY-NAME-01：读取通知内容名称 | 普通列表请求返回当前可读名称或对应的不可用状态，权限变化后重新读取时不泄露原名称 |
| NT-10：已认证教师订阅所授课程新评价汇总 | 开启后按日聚合推送课程新增公开评价数，关闭或待审撤回内容不发送，载荷不含匿名作者身份 |
| NT-11：教师主页资料申请处理通知 | 通过和拒绝通知仅发给原申请账号，回执按当前资格与归属授权。默认列表、分组未读统计和批量已读均包含该通知 |

## 配置与后续事项

迁移沿用旧记录的 `read_at`，空值表示未读。若历史记录有独立证据确认已读但缺少该字段，以最早能证实已读的操作或观察时点回填。只有证据表明通知在创建时已读，才采用创建时间。

教师主动订阅的授课反馈汇总保留为待实现规格。默认按日汇总，仅包含所授课程名称和新增公开评价数，排除匿名作者身份及未公开内容。

邮件、QQ 和客户端推送的接入待验证。外部渠道启用后按用户偏好发送。免打扰延后外部推送，站内通知仍可查看。
