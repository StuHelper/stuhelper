# 机器人娱乐功能

## 范围

掷骰子和自助禁言属于独立的“娱乐功能”菜单。群聊管理处理违规处罚，信息查询处理全站关联记录。两项娱乐动作由 groups 的群命令接口提供。

## 用户与管理员体验

用户主动调用已启用的娱乐命令。掷骰子返回本次结果与骰子面数。自助禁言按配置的概率和保底规则处理发起者。触发禁言时返回时长，启用保底时还会返回剩余次数。

管理员按群启停娱乐能力，配置骰子面数、自助禁言概率、时长、冷却与保底。未配置的功能不执行。处于冷却期时返回剩余秒数。

自助禁言仅作用于发起者，无违规记录。禁言到期自动结束，群管理员可提前解除。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| BE-01：用户使用已开放的骰子命令 | 展示该次结果及适用规则 |
| BE-02：用户主动使用自助禁言 | 结果与对发起者的实际处理一致，不登记为违规处罚 |
| BE-03：某群未开放对应娱乐功能 | 明确说明不可用，不执行对应动作 |
