# 个人中心

## 范围

个人中心集中提供本人资料、认证、账号绑定、内容和服务入口。已开放页面在桌面侧栏及手机导航中可达。

## 入口与行为

| 区域 | 用户可以做什么 |
| --- | --- |
| 个人资料 | 查看和编辑昵称、头像、简介等个人资料 |
| 认证情况 | 查看学生认证和实名认证，进入认证详情 |
| 账号与安全 | 查看脱敏号码，绑定、更换或解绑手机号 |
| 学生认证管理 | 查看学校与学习经历，提交撤销或删除申请，查看管理员处理结果 |
| QQ 绑定 | 分别查看三项状态，生成私聊验证码，发起 QQ 互联 OAuth，逐项解绑并查看入群提示 |
| 我的内容 | 查看本人评课、课程、教师和资料收藏、投票记录、评课草稿和上传资料，回到对应详情继续操作 |
| 我的群 | 查看本人已加入或申请中的群、处理状态、截止时间、缺少条件和下一步入口 |
| 我的课程 | 正式 Web 暂停此入口，开放条件见[课表规格](my-courses.md) |
| 授权应用 | 查看第三方应用及用户授予的业务信息范围，取消应用授权 |
| 存储贡献 | 查看本人贡献容量、占用、期限和退出进度 |
| 积分与 Ivory | 分别查看积分和 Ivory 余额、明细、到期信息及退款进度，进入充值或购买积分流程 |

资料管理沿用[资料规格](resource-sharing.md)：允许编辑、更正和提出下架申请，不提供普通删除。认证操作沿用[认证规格](student-verification.md)，不能在个人中心另设直接撤销学生资格的快捷入口。

我的评价中，草稿可继续编辑。已发布的课程评价、导师评论和回复在首次发布五分钟内提供删除与撤回重编。撤回内容进入草稿箱并显示 24 小时到期时间，根评价删除或到期时整条讨论永久删除，具体行为见[评价规格](academic-content.md)。超过发布窗口的修改与删除由管理员处理。个人中心不提供匿名与署名切换申请。

学生资格、实名和手机号分别展示，不能用一个“已认证”标志代替所有状态。

## 群名片字段许可

用户在个人资料中逐字段允许群名片使用学校、年级、院系、姓名、学号、性别与自由昵称。七项默认全部关闭，与公开主页展示偏好独立。允许某个字段不代表该字段已有可用事实。

profiles 保存 group_card_consent，修改时使用当前修订号与幂等键。提交许可对象须包含七个布尔值，省略整个对象保留原设置。许可、资料修订、幂等结果与事件同事务提交，旧修订或同键不同内容被拒绝。

群名片读取逐次检查服务身份、学校范围、group_card 用途及用户当前许可。未许可或事实缺失时不返回字段值，许可撤回后后续读取立即生效。公开主页不返回群名片许可，读取失败不返回部分事实。

“我的群”的本人记录、资格待确认与下一步入口遵循[群服务规格](qq-group-services.md)。未知事实不能解释为满足资格，也不能根据缺失字段推测用户身份。

## 公开个人主页

基础主页向游客显示昵称、头像和简介。学校、认证徽章、学院、署名评价和资料默认公开，年级默认隐藏，六项均可关闭。公开主页接口只返回基础资料与获准显示的当前学校事实，署名评价和资料由各自入口执行读取授权。

匿名内容与主页分离。真实姓名、证件信息、联系方式及账务明细仅通过各自获授权的业务接口访问。

## 登录、设备与绑定

注册、登录与找回由独立 SSO 提供。个人中心支持退出当前设备和退出全部设备，界面说明撤销的是本应用会话。共享 SSO 与其他应用会话按各自规则管理。

手机号在 StuHelper「账号与安全」查看和管理。绑定或更换要求再次确认本人身份并验证新号码。服务端检查号码占用。解绑须保留可用登录方式，并先关闭短信 MFA。并发写入和审计限制见[应用会话规格](sso-compatibility.md)。

QQ 绑定按 OneBot、QQ 互联、官方机器人三项独立验证和解绑，三项全部完成才提供整体绑定事实。发生归属冲突时走账号找回或管理员核查。解绑后，相关操作按当前资格配置判断。

## 业务账号注销

用户提交注销申请后进入 7 天冷静期，可在截止时刻前登录撤销。冷静期结束后，Backend 定时扫描到期申请，自动推进没有阻断的申请。宿主重启后从已保存的步骤继续处理。

资产未结清、退款在途或依赖失败时，系统保存阻断原因和已完成步骤，并记录脱敏告警。阻断解除后，当前有权管理员可以继续处理同一申请。

注销 StuHelper 业务账号不删除共享 SSO 账号，也不删除 AI、Store 等其他应用的账号或业务记录。页面在提交申请前清楚说明处理范围。

注销完成后，关闭标记在保留期间阻止同一 SSO 身份自动重建或进入本应用业务账号。恢复请求由管理员处理，旧内容和资产不因再次登录恢复关联。标记与个人资料的期限见[数据保留与删除](data-retention.md)。

注销无法核实资产状态时不得完成，账务模块提供资产核对与结清能力。

账务模块未装配时，仅在持久安装历史明确记录 billing 从未安装的情况下跳过资产步骤。开放平台同样仅在 open-platform 明确从未安装时跳过授权撤回。曾安装但关闭、记录缺失或查询失败时等待恢复。

云盘托管、存储贡献和教师身份绑定也按持久安装历史核对。资产、授权与内容步骤均保存跳过的模块名称。后续步骤失败或管理员续办时，沿用已确认的记录。

注销申请明确告知并要求用户确认：正式注销时清零长期积分、限时积分和待抵扣记录，不兑换现金或 Ivory。冷静期内撤销申请不改变积分。资产核对必须确认 Ivory 余额为零、退款完成且没有结果未明的支付，再原子冻结后续账务写入并清零积分。

注销同时通过 qq-binding 删除三项身份、验证码与绑定状态，并阻止后续绑定写入。

公开资料保留原作者、来源、许可证和正文，注销仅移除上传账号的公开关联。公开评价移除账号署名、个人主页关联和认证标签，保留评价正文与讨论结构。

## profiles 模块边界

昵称最多 20 个 Unicode 码点，个人简介最多 120 个 Unicode 码点，前后端按相同方式计数。首次登录依次使用合规的 SSO 显示名和用户名，都不合规时由用户填写。不修改 SSO 用户名。

实名详情显示证件类型、脱敏姓名和脱敏证件号。证件类型取自核验凭据。姓名保留末字，证件号保留首尾位，星号数等于遮盖的 Unicode 码点数。证件类型或脱敏依据缺失时返回服务错误。姓名至少 2 个码点，证件号至少 3 个码点。

profiles 拥有昵称、头像引用、简介、公开展示偏好、群名片用途许可和业务账号状态。identity 提供登录身份，verification 提供校园资格。修改资料使用本人账号与修订号，冲突时返回当前版本供用户选择。

本人可通过 Backend 预览公开主页草稿。预览要求登录与 CSRF 令牌，不写入资料。启用头像用途后，本人可选用已审核且就绪的头像版本，游客通过公开主页的头像接口读取当前版本。替换、清除与注销会释放旧引用，中断后由后台继续处理。

注销流程记录资产处置、会话撤销、授权撤回与资料处理进度，重复请求沿用同一操作。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| PC-01：有学生资格但未独立实名 | 分别展示真实状态，发布评课按已确认门槛判断 |
| PC-02：从我的草稿返回编辑 | 回到本人未完成内容，可以继续编辑 |
| PC-03：从我的资料管理上传内容 | 可编辑、更正或申请下架，不出现普通删除入口 |
| PC-04：取消第三方应用授权 | 应用授权状态更新，不等同于注销账号或撤销学生资格 |
| PC-05：用户首次打开公开主页 | 学校和认证徽章默认公开，可由本人调整，匿名内容不关联 |
| PC-06：绑定已属于其他账号的手机号或 QQ | 已查到其他账号占用时提示找回或人工核查 |
| PC-07：管理员批准已完成资产处置的注销申请 | 注销本应用业务账号并匿名化公开内容，共享 SSO 与其他应用保留 |
| PC-09：冷静期内登录并撤销注销申请 | 申请撤销，账号与资产不受撤销申请影响 |
| PC-10：SSO 显示名和用户名都不合规 | 登录成功并要求用户填写昵称 |
| PC-11：查看本人实名详情 | 返回已核验的证件类型、脱敏姓名和脱敏证件号。依据缺失时返回服务错误 |
| PC-08：本人修改公开昵称 | 使用当前修订与幂等键，重复提交仅修改一次，同键不同内容与旧修订拒绝，其他账号资料相互隔离 |
| PC-12：设置或撤回群名片字段许可 | 七项默认关闭，仅返回当前许可且可取得的字段；与公开主页偏好独立，修订冲突与事务失败不产生部分修改 |
| ME-MENU-01：进入本人功能页面 | 桌面与手机的个人中心提供所有已开放本人页面入口，关闭功能不显示入口 |
| PC-13：满 7 天冷静期且无阻断的注销申请 | 后台有界巡检自动幂等完成注销与公开内容匿名化；存在资产未结清或依赖故障时保留人工队列并触发告警 |

## 注销处理与恢复

注销内容步骤逐模块幂等执行：删除本人收藏、收藏夹和相关幂等响应，投票匿名保留并继续计入统计。失败保存进度并允许重试，已完成模块重复执行不会恢复账号关联或收藏。

管理员通过 `blocker` 与 `completed_steps` 查看资产或依赖阻断。阻断解除后，以当前权限继续处理原申请。自动巡检的单轮批量、并发和执行时间须受限，停机时保留已完成步骤。
