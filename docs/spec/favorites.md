# 收藏与收藏夹

favorites 独立拥有课程、教师、资料收藏和收藏夹。目标存在、种类、当前内容准入及可见状态通过所属模块公开接口校验，模块之间不直接访问对方数据库。

## 归属与展示

新增收藏要求内容准入。本人列表、取消、移动和收藏夹管理仅要求登录。资格失效后仍可管理本人记录，其他账号不能读取、移动或取消这些记录。

收藏回执只返回名称快照、目标 ID、种类、收藏夹、时间和修订。对象详情、评分、正文与文件仍通过原业务入口检查当前权限。目录已不存在的历史目标可以只保留 ID。

同一用户对同一目标只有一条收藏，每条收藏只属于一个夹。重复调用新增接口返回原记录，指定另一收藏夹时返回 409。删除普通夹会将收藏原子移入默认夹，并递增受影响收藏的修订。

收藏夹名称经 NFC 归一化并去除首尾空白，长度为 1 至 20 个 Unicode 码点。同一账号下名称区分大小写且不得重复。改名保留收藏夹 ID 和归属。

默认夹固定置顶，可以改名或用空名称恢复本地化默认标签。删除请求只接受普通夹。单账号默认最多保存 200 个收藏夹和 10000 条收藏，删除后释放配额。

## 接口与一致性

列表每页最多 100 条。收藏支持收藏夹、种类与名称筛选，提供新增时间和名称排序。游标绑定账号与筛选条件。收藏夹返回收藏总数与按种类拆分的计数，均独立于收藏列表筛选。

`GET /api/v1/favorites/items` 支持 `target_ids`，以逗号分隔最多 100 个目标 ID，必须同时提供 `kind`。每项长度为 1 至 200 个 Unicode 码点，首尾空白、空项和重复参数返回 400。重复 ID 按一个目标查询。

目标过滤只返回本人对应收藏，与收藏夹、名称等条件取交集，沿用 `limit` 和 `after` 分页。游标绑定完整目标集合，列表不读取目标正文，也不重新检查新增资格。

所有写操作使用幂等键，修改和删除同时检查修订。相同请求返回原结果，相同键不同内容或过期修订返回 409。业务写入、审计与幂等记录在同一事务中完成，数据库唯一约束防止重复收藏和重名。

favorites 当前开发分支提供按目标设置与取消接口。已有收藏可按目标原子移动，新建仍检查当前准入。取消不存在的收藏返回 `removed=false`。批量移动与取消每次最多处理 100 条本人收藏，整批原子提交。

开发分支同时提供按需刷新标题和本人导出。目标当前可读且标题变化时才更新快照与修订。导出每页最多 500 个夹和 500 条收藏，两组共用游标，包含空夹与规范目标路径。

生产的收藏入口与接口版本以已发行组合为准。

## 验收场景

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| FAV-01 | 跨账号访问、认证失效、并发新增、重名、移动与删除 | 归属隔离，拒绝新增，允许本人管理，每个目标一条记录，收藏夹名称唯一 |
| FAV-02 | 按目标查询收藏、输入边界与分页 | 只返回本人指定种类和目标，拒绝空项和超限输入，游标绑定筛选条件 |

账号注销时删除本人收藏、所有收藏夹和相关幂等响应。保留最小关闭标记以阻止并发写入和请求重试恢复数据。删除与关闭标记同事务提交，失败可恢复，其他账号的收藏不受影响。
