# 课程、教师维护与教务导入

## 范围

管理员维护 StuHelper 中用于查询的课程和教师资料，查看教务导入来源、进度及结果。该业务范围已确认；课程与教师概念见[课程规格](academic-content.md)，学生侧入口见[我的课程与课表](my-courses.md)。

## 目录维护

管理员在自己的范围内检索课程与教师，查看课程基本信息、院系、学期、开课和授课关联，维护目录中需要更正或补充的信息。修改前可以看清对象及其关联，避免将同名但不同学校的教师或课程混为一项。

目录信息缺失时保留未知。范围内管理员可补充、更正与合并重复对象，人工确认字段优先于后续导入，冲突展示给管理员处理。合并保留旧链接、评价和资料关联，停用不删除历史。

合并前展示源对象、目标对象及当前修订。合并后使用目标对象的资料，源名称作为别名保留，源记录与历史仍可追溯。源对象的其他字段不自动覆盖目标。确认前任一对象变化时要求重新预览。停用仅从默认目录移除，旧链接和关联仍可查询。

## 教师公开目录依据

授课记录、有效官网匹配和已核实人工资料均可作为教师目录的展示依据。授课记录从截止学期起算。目录、筛选、搜索和公开详情使用三项依据的并集，并继续检查当前准入与教师状态。三项计数可能重叠，人工资料计数独立于官网匹配计数。

自动匹配要求姓名、单位均一致，且目录教师与官网站点双方唯一。姓名和单位可以统一 Unicode 兼容字符、空白及完整校名前缀。同名同单位多条记录、多个站点、单位缺失或不一致等情形进入人工处理。

目录列表、筛选选项与计数在 catalog SQL 分页和聚合前按当前依据过滤。详情与搜索也核对当前依据，读取执行既有准入规则。依赖姓名与单位的自动关联在教务身份发生变化后失效。

教师及任课写入在同一事务更新授课依据，完整课程同步后再次核对。官网按完整快照原子替换，拒绝旧修订、同修订不同内容及提交前发生变化的匹配候选。抓取失败时沿用上一完整快照和当前授课依据。

目录的姓名、职称和院系来自教务数据，官网资料按[教师主页](academic-content.md#教师评分与主页)展示。个人选课读取须有本人有效学校数据认证。获授权的维护管理员可以读取隐藏档案，用于修正或合并。

catalog.directory 通过公开接口取得 reviews 与 favorites 聚合，任一依赖不可用时该目录能力返回不可用。

## 目录投影与教师官网刷新

Catalog 持有平台起始学期 2023 年秋季，并通过公开 Go 接口提供排序下限。学期列表、选项、筛选、Admin 学期列表和校历从该学期起提供。未能确认排序的学期不进入这些列表。

目录的截止配置可进一步收窄公开开课范围。课程详情学期筛选和评价编辑器使用同一课程的可见开课学期，按学期倒序排列，教师筛选只使用范围内的任课记录。目录、统计和搜索使用同一发布投影。筛选选项仅保留非零结果，完整导入和配置变化先重建投影，再原子发布。

教师官网每月自动增量刷新，全量仅由管理员手动触发。查看任务、人数和未匹配原因需要 catalog.teacher-sites.read，触发需要 catalog.teacher-sites.refresh，两项均依赖 identity 提供当前权限和学校范围。

刷新请求使用幂等键，同一内容重放返回原任务，冲突和已有活动任务返回明确拒绝。任务记录等待、执行、成功、失败或超时。失败保留上一完整快照，未匹配原因、总数、分页和统计均绑定快照修订。

刷新状态与原因统计只返回任务、汇总及站点摘要。查看、触发、重放与权限拒绝记录审计。临时网络故障允许恢复轮询，权限撤销后清空已显示数据并停止自动读取。

正文图片因全站限额回退为链接时，刷新继续发布，任务记录容量状态。运维巡检沿用现有告警渠道，只报告容量状态。后续成功刷新未触发限额时恢复正常。刷新失败保留上一份完整快照和告警状态。

## 教师官网人工处理

具有 `catalog.teacher-sites.read` 权限的管理员可在当前学校分别分页查看待处理站点与目录教师。列表提供未匹配或歧义原因、站点摘要及候选。管理员可查询已处理站点，以便核对与撤销决定。

具有 `catalog.maintain` 权限的管理员可在同一学校绑定站点和目录教师、标记站点不对应，或撤销当前决定。操作携带当前修订和幂等键。相同请求重放返回原结果，不同内容复用键或提交过期修订时拒绝操作。决定与审计同一事务保存。

一个有效站点与一位有效目录教师最多形成一组现行关联，人工绑定优先。标记不对应只排除该站点，撤销后重新计算当前快照的自动关联。目录教师停用或被合并时隐藏官网资料，保留原决定。

完整刷新确认站点消失后，下架该站点的资料、头像、正文媒体与官网依据。保有其他目录依据的教师继续可查。后台保留人工决定和审计，已从名单移除的站点只允许撤销决定。同一站点标识重新出现且原目录教师仍有效时，恢复人工绑定。

站点仍在名单中但详情页返回 404 时，采集资料、头像和正文媒体下架。管理员可标记不对应或撤销既有决定。绑定要求详情页当前可用。

## 官网字段白名单与主页管理

学校管理员使用同校 `catalog.maintain` 权限维护官网字段白名单。默认展示已识别的结构化字段、学术栏目和头像。其他字段标签及栏目标题逐项审核加入名单，名单变化有修订与审计。

教师主页使用当前白名单筛选采集值。管理员明确保存的覆盖值可以补充资料，并优先于采集值，即使该字段不在白名单。撤销覆盖后采用当前获准展示的采集值。字段隐藏优先于覆盖，刷新保留名单和人工设置。

官网简介中的个人主页以 HTTP 或 HTTPS 外链展示。单位、职称按规范化后的完整值与教务目录去重。院系旧名按更名配置和同校别名记录转换，教师目录关联由管理员核对。

邮箱、电话和办公地点按读者操作展示。普通详情和摘要遮盖邮箱，读者点击后重新核对学校准入和当前字段控制。只展示来源明文或已获准的人工更正。

隐藏邮箱、电话或办公地点后，公开字段与栏目同时过滤已识别的重复值。多行联系方式按行识别，匹配兼容空白与标点差异。

状态分为显示、隐藏和停止展示。隐藏可恢复，停止展示须管理员明确解除。这两种状态均收回主页资料、头像和正文媒体的访问，已发出的本站图片地址随即失效。目录中的教师、教务职称、院系与评价按既有规则读取。

管理员可以上传 JPEG 或 PNG 替代头像。上传时校验格式、大小和像素并重新编码。当前已发布头像通过 StuHelper 地址读取，继续核对教师详情准入及主页可见状态。

白名单与主页设置使用修订和幂等键写入。后台在同一事务保存处理结果和审计。接口、上传限制与字段选择器见 [catalog 教师目录规格](https://github.com/StuHelper/stuhelper-catalog/blob/develop/docs/spec/teacher-directory.md)。

合并整组与逐项覆盖后，每页最多保存 128 项有效人工通用字段和 64 项有效人工栏目。超限返回 `409 teacher_homepage_capacity_exceeded`。管理员可减少或合并人工项后重新提交。

## 教师官网正文媒体

详情页以 `GET /api/v1/catalog/objects/{id}/teacher-homepage/media` 读取正文媒体。按来源的简介、研究方向或栏目展示，同一栏目可只有媒体。接口检查教师详情准入、当前有效的官网匹配、主页状态和该字段或栏目的当前展示设置。

学校正文引用的 HTTP(S) 图片每次请求及跳转都须确认全部解析地址为公网 IP，只连接该次核验的地址。校内私网图片只从单独批准的离线包导入，逐项匹配学校原页与原图引用。缺少可用授权副本时省略该媒体项。

正文图片通过格式、尺寸和完整解码校验后，保存在头像使用的获准存储中。下载与存储的单张图片各限 20 MiB。采集暂存和目录发布均按内容摘要去重，并执行全站 2 GiB 的正文图片限额。容量不足时停止新增图片，沿用已验证的现有副本。

有副本的图片通过教师主页的 `/images/{image_id}` 以 GET 或 HEAD 读取。隐藏或覆盖来源字段、收回栏目白名单权限后，接口重新检查图片在该主页是否仍有可见来源。失去所有可见来源的图片地址立即失效。

超过单张或全站限额、无法取得或校验失败的公网或内嵌图片显示为学校原内容页的链接。视频和所有下载附件（含 PDF）显示为原站链接，由用户点击打开。无法安全表示原站链接时返回学校原内容页。页面只用 StuHelper 地址加载图片副本。

## 教师本人资料申请

当前有效教师认证须准确关联到相应目录教师。通过核验的本人可以提出更正、补充或隐藏申请，并查询本人回执。更正和补充可附替代头像，审批前仅获授权的本校管理人员可预览。隐藏可针对字段或整个主页资料区。

学校管理员在管理范围内处理待审申请。批准更正或补充时重新核对本人当前绑定，按申请内容保存覆盖值并记录已核实人工资料依据。拒绝及只申请隐藏不产生该依据。处理须核对申请修订，批准时还须核对主页设置修订。结果与审计同一事务保存。

批准后的有效人工项超限时，接口返回 `409 teacher_homepage_capacity_exceeded`，申请继续待审。管理员可调整现有人工项后，按当前修订重新审批。

尚无授课或官网依据的教师可在更正或补充获批后取得目录资格，并在投影发布后由符合准入的用户通过目录和搜索发现。资料隐藏、停止展示及官网刷新保留该资格。教师停用后停止公开，合并不转移人工资料依据。

批准和拒绝均向原申请账号发送[站内通知](notifications.md#站内通知与操作)。打开回执时重新检查账号和教师归属。申请材料依照[数据保留](data-retention.md#保存范围)清理。其他用户可使用[教师主页投诉](content-management.md#教师主页投诉)或联系 `legal@stuhelper.com`。

## Web 目录查询

课程列表与教师列表分别维护搜索词和筛选条件。点击导航切换列表时，页面读取当前列表的状态，搜索、院系筛选和清空操作仍可使用。浏览器后退恢复对应历史记录的条件，地址栏保持页面路径。

学院分面、按学院浏览的分组和院系下拉均按学校映射后的正式系号排序。纯数字按数值升序，其次是 B 前缀单位（按数字后缀），再按代码排列其余有代码的单位，无代码单位排最后。组内相同排序值按名称、ID 定序。课程和教师列表仍默认按热度排序。

课程目录每页读取 50 条，教师目录每页读取 100 条，接近列表末尾时继续加载。按学院分组先读取 5 条，展开后按 100 条分页。各分组独立请求，始终提供完整列表入口，不以学院计数之和推算未分组课程数。

改变筛选时保留上一页内容至新结果返回，明确显示加载状态。请求失败后清除失效结果并提供重试。快速查看先展示对象名称，再加载评价摘要和图表。

## 导入管理

管理员可查看已接入来源，查看各次导入任务，并对已启用来源手动发起一次导入。任务显示等待、处理中、成功或失败及可理解的结果，失败不能表现成来源没有数据或所有课程已消失。

导入的业务对象包括学期、课程、教师、开课、时间地点和本人选课关联。来源按实际接入能力启用，支持导入预览与手动导入，同步频率由后台配置。维护对象是 StuHelper 的展示资料，不赋予管理员向学校系统执行选课、退课、排课或改成绩的能力。

## 选课与任课记录

课程评价的选课证据由 catalog 提供。学校、课程、学期和教师使用稳定 ID；教学班和教师授课关系保留来源及有效学期。管理员可在授权学校范围内导入教务数据，用户也可授权学校适配服务读取本人教务选课记录。接入方式由私有 campus-adapters 实现。

导入预览区分新增、更正、冲突和未能关联的记录。确认后保存学生账号、课程、学期、任课教师集合、来源标识、获取时间和修订。选课名单与学校会话仅供获准服务使用，普通目录返回课程和教师，开课、教学班、任课关系与排课仅供受信模块及获准维护管理员读取。本人查询只返回自己的选课与教师选项，管理员查询按学校及业务范围授权并记录审计。

各学期的任课关系分别保存。评课候选采用该课程在目录截止范围内的开课学期和所选学期的公开任课教师。学校数据认证有效时，可按本人选课记录标记匹配项。评价提交保存选课状态及教师归属快照。归属更正保留修订和管理处理结果。

本人选课来源不可用时，评价保存 unknown 并使用公开教师。课表和选课查询返回不可用。学校凭据的保存与销毁遵循私有适配服务的数据保留规则。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| CO-01：管理员查找同名不同学校的教师 | 可区分对象及其关联，不自动合并 |
| CO-02：课程信息不完整 | 可看到缺失项并按许可范围补充，不以零或默认值伪造信息 |
| CO-03：手动发起已启用来源的导入 | 可查看该次任务和真实处理结果 |
| CO-04：导入失败 | 说明失败，不把任务显示成成功或将未知状态显示成无课程 |
| CO-05：导入本人已选课程及合授教师 | 用户可查询该课程和准确的教师候选 |
| CO-06：下一学期更换任课教师 | 新记录保留新学期，历史评价仍可追溯来源记录 |
| CO-07：普通用户请求其他学生的选课名单 | 按数据归属拒绝，响应经过脱敏 |
| CO-08：合并确认重复的课程或教师 | 保留旧链接、开课、选课与评价关联，跨学校操作被拒绝 |
| CO-09：停用目录对象 | 默认列表不展示，历史及旧链接仍保留，可重新启用 |
| CO-10：预览导入后资料发生变化 | 预览不写入业务数据，确认拒绝旧预览并保留人工更正 |
| CAT-REFRESH-01：刷新并发、重复与超时 | 持久任务互斥，相同幂等键返回原任务，超时不发布部分结果 |
| CAT-REFRESH-02：未匹配清单读取 | 原因筛选、分页、总数和修订一致，失败保留完整旧快照，不泄露候选身份 |
| CAT-REFRESH-03：查看与触发权限 | 两项权限及学校范围独立检查，查看、触发和拒绝均记录审计 |
| CAT-OPTIONS-01：目录选项更新 | 仅返回非零结果，元数据和来源变化后随投影版本更新 |
| CAT-TEACHER-01：授课与官网依据 | 两项既有依据任一成立即可保留，公开读取、筛选和计数执行同一范围 |
| CAT-TEACHER-02：官网重复导入、撤销与候选变化 | 相同快照无额外业务效果，旧修订与匹配后的同名变化被拒，撤销后搜索使用当前依据 |
| CAT-TEACHER-03：维护隐藏教师 | 范围内维护管理员可以修正与合并，普通读取保持过滤 |
| CAT-TEACHER-04：读取官网资料和照片 | 当前 verified 用户可读取有效关联的采集资料与本站照片，旧版详情及摘要须显式请求，目录列表和搜索只返回目录信息 |
| CAT-TEACHER-05：人工处理列表 | 按学校和权限分别分页读取站点与目录教师及其候选，越权请求被拒绝 |
| CAT-TEACHER-06：人工绑定、标记不对应与撤销 | 决定与审计原子保存，重复提交只生效一次，过期修订与跨学校目标被拒绝 |
| CAT-TEACHER-07：刷新遇到人工决定和站点移除 | 完整刷新保留人工决定，站点消失后下架对应采集资料与照片，同一站点重新出现后恢复有效的人工绑定 |
