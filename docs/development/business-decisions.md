# 业务规则与延期事项

## 范围

业务范围和延期事项按所属规格维护。通用文件、存储、贡献及激励各自维护业务职责。三份完整副本为目标，两份为首次发布门槛。保护分类映射及持续授权仍待评审。受限文件加密与在线阅读器延期，详见[存储实施](storage-module.md)。

## 已确认主题

| 主题 | 当前规则 | 维护位置 |
| --- | --- | --- |
| 课程、教师与导师 | 课程五维评价，教师评分先算课程均分再对课程等权平均，导师仅文字评论 | [评价规格](../spec/academic-content.md) |
| 身份与内容修改 | 默认匿名、可昵称署名，同一讨论身份一致，五分钟内删除或撤回重编、24 小时草稿到期清理，管理员处理其他修改与删除 | [评价规格](../spec/academic-content.md) |
| 草稿与举报 | 多份跨端草稿，冲突选择版本，处理中举报可补证据，结案后可因新事实再举报 | [评价规格](../spec/academic-content.md) |
| 内容运营 | 可配置审核、分类、敏感词、复核与批量预览，有效与优质内容有明确认定方式 | [内容管理](../spec/content-management.md) |
| 账号与个人主页 | 学校与徽章默认公开可调整，绑定唯一归属，注销只处理本应用 | [个人中心](../spec/personal-center.md) |
| 学生资格与实名 | 完整规则私有维护，公共模块只使用必要资格结论 | [认证对接](../spec/student-verification.md) |
| 服务范围与内容准入 | 当前只服务北航，不做多租户。内容准入要求有效校园资格（含校友和临时新生）或有效教师认证，服务端读接口、搜索和统计同样执行；不保留评价预览；认证失效后仍可管理本人记录（含我的课程） | [资格配置](../spec/action-eligibility.md) |
| 动作资格 | 全站默认和授权范围覆盖，可收紧或放宽，后续操作生效并保留既有记录 | [资格配置](../spec/action-eligibility.md) |
| 资料与作品许可 | 原创/转载简化填写，版本先审，保留文件原名，目录只打包有权内容 | [资料共享](../spec/resource-sharing.md) |
| 账户、会员与交易 | 已确认规则移入私有账务模块，金额与期限按配置管理 | [账务对接](../spec/wallet-and-points.md) |
| 群管理 | 两种认证准入及独立动态口令，名片、黑名单、消息规则、聊天工作台与订阅均保留 | [QQ 群服务](../spec/qq-group-services.md) |
| 信息查询 | 管理后台按对象范围和字段权限查询，展开敏感信息须单独授权。机器人默认关闭，启用后群聊可按请求人权限直接返回普通摘要和掩码字段，敏感展开请求返回 403 并记录审计。批量与导出分别授权 | [信息查询](../spec/information-query.md) |
| 娱乐 | 骰子与自助禁言按群配置，主动参与，管理员可提前解除 | [娱乐功能](../spec/bot-entertainment.md) |
| 目录与课表 | 人工确认字段优先，合并保留关联；“我的课程”在生产保持关闭，不向用户展示开课、教学班及其时间地点 | [目录维护](../spec/catalog-operations.md)、[课表](../spec/my-courses.md) |
| 热度与趋势 | 指标权重、窗口、样本量可配置，教师评分与导师评论分开 | [发现与统计](../spec/discovery-and-statistics.md) |
| 通知 | 站内优先，互动可关闭聚合，外部渠道用户选择，免打扰延后外部推送 | [通知](../spec/notifications.md) |
| 开放平台 | 应用审批、逐项授权、最小字段、撤回与第三方删除义务 | [开放平台](../spec/open-platform.md) |
| 存储贡献 | 实际接入服务商，退出先迁走文件，自愿上榜，公开透明度 | [存储贡献](../spec/storage-contribution.md) |
| 通用文件与存储 | 全系统能力，课程资料是使用方；贡献和激励独立，账号来源与协议分开，实例按分类与范围准入；不考虑 BHpan 整体服务故障 | [存储设计](../design/storage-architecture.md) |
| 存储冗余目标 | 首期总计三份完整副本，跨独立账号；首次发布门槛为两份，第三份异步补齐 | [放置与恢复](../spec/storage-placement.md) |
| 存储执行器部署 | 首期同进程装配并设置后台任务与资源预算，执行器保留独立启动入口；按实测和运维需求启用独立进程或容器 | [部署规划](../design/storage-architecture.md#执行器部署与资源预算)、[执行器部署](storage-module.md#执行器部署) |
| 管理后台 | 可配置角色模板、对象范围、独立敏感权限及并发配置提示 | [管理操作](../spec/admin-operations.md) |
| 客户端与迁移 | 当前客户端为 Web 和 stuhelper-admin。身份数据的保留、迁移及复查按 SSO 兼容范围执行 | [开发路线](rewrite-roadmap.md)、[SSO 兼容](../spec/sso-compatibility.md) |
| 品牌与产品边界 | 沿用 StuHelper 和纸飞机品牌，不建设作业实验系统或学校教务写入功能 | [业务范围](../design/business-scope.md) |
| 仓库边界 | 按业务模块拆仓，认证、学校适配、账务与生产配置私有 | [多仓库设计](../design/module-repositories.md) |

## 后端与客户端规则

| 主题 | 当前规则 | 规则位置 |
| --- | --- | --- |
| 账户展示 | 积分与 Ivory 分别展示余额、明细、到期信息和退款进度 | [账务对接](../spec/wallet-and-points.md) |
| 收藏 | 独立 favorites 模块拥有课程、教师、资料收藏和收藏夹 | [收藏规格](../spec/favorites.md) |
| 账号注销 | 7 天冷静期内可撤销。规格要求期满后自动处理无阻断申请，当前由管理员推进，自动巡检待接入 | [个人中心](../spec/personal-center.md) |
| 认证期限 | 普通认证长期有效，只对限时凭证提示到期 | [学生认证](../spec/student-verification.md) |
| 本人身份字段 | 展示服务端返回的证件类型、脱敏姓名与证件号 | [个人中心](../spec/personal-center.md) |
| 昵称 | 最多 20 个 Unicode 码点，首次登录依次尝试 SSO 显示名和用户名，都不合规时由用户填写 | [个人中心](../spec/personal-center.md) |
| 主页开关 | 学院、年级、署名评价、资料、学校和认证徽章都可关闭 | [个人中心](../spec/personal-center.md) |
| 基础主页 | 游客可见，关联内容按各自权限显示 | [资格配置](../spec/action-eligibility.md) |
| 开放平台范围 | 独立模块已发行，生产保持关闭。学生认证状态、学校、QQ、个人资料、课表、目录和公开评价分别审批与授权。目录与评价要求内容准入 | [开放平台](../spec/open-platform.md) |
| 资料预览 | 与下载使用同一权限检查 | [资料共享](../spec/resource-sharing.md) |
| 原创资料授权 | 修订后的用户条款已定稿，生效后适用于明确同意新版本的原创上传 | [原创授权政策](../spec/resource-sharing.md#已确认的原创授权政策) |
| 访问权 | 不新增申请或审批，按实际缺失条件提示；投诉入口独立，只要求登录 | [资料共享](../spec/resource-sharing.md) |
| 受限资料购买 | 组合支持积分与 Ivory 解锁、会员覆盖及交付回执。生产仅开账务，未解锁资料不交付文件字节 | [资料共享](../spec/resource-sharing.md) |
| 互动 | 新增点赞、点踩、收藏和举报要求内容准入，本人已有记录可继续管理 | [资格配置](../spec/action-eligibility.md) |
| 教师认证 | 首期人工审核并绑定教师档案，自动核验后补 | [学生认证](../spec/student-verification.md) |

## 延期事项

| 事项 | 当前处理 |
| --- | --- |
| 社交动态、分区、关注、私信与站内群聊 | 独立延期，评价自身互动继续保留 |
| 微信小程序、Android、iOS、HarmonyOS | 暂时搁置，保留参考设计 |
| 存储保护分类与审批范围 | 已实现按实例和范围控制放置，分类映射与审批范围待评审 |
| 受限文件的应用层存储加密 | 明确暂不实现；需要密文的用途关闭，不因延期自动批准明文保管 |
| 在线阅读器、加密容器与泄露溯源 | 保存未来参考设计，暂不实现，不作为普通资料下载的强制条件 |
| 开放平台商业收费 | 独立延期，接入与授权业务继续保留 |
| 认证服务商与账务后续渠道细节 | 在私有模块保留明确延期记录 |
| 首期范围以外的离线下载 | 延期，先缓存公开目录、本人课表与草稿 |
