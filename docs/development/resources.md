# 学习资料实施

## 当前范围

生产已装配 resources，管理资料分类、字段、课程关联、版本、审核、访问授权、申请和目录打包。文件内容由 media 与 storage 保存，课程对象由 catalog 校验，审核由 moderation 执行。

Web 与 stuhelper-admin 的资料入口为 `/resources`，课程主页提供关联入口。用户可筛选字段、查看年份分组、上传、维护本人资料、提交申请并下载分包。管理员可配置分类和目录、审核、授予或撤回访问权。

| 组件 | 当前实现 |
| --- | --- |
| resources | PostgreSQL 独立运行身份、分类修订、版本快照、幂等与事务、审核任务、当前访问权、目录与下载包 |
| media | 文件上传会话、本人文件清单、引用发布、独立审核读取、完整下载和 ZIP 清单 |
| storage | 原三副本目标与两副本发布条件，另设独立审核读取权限，不改变发布状态 |
| moderation | resource 内容种类、学校范围队列、审核结果、申请复核与失败重试 |
| backend | 课程、审核、资料和媒体公开接口装配，独立服务主体及共享身份与资格端口 |
| Web | 配置分类与字段、课程关联、上传、资料详情、申请列表、目录与多包下载 |
| stuhelper-admin | 分类字段与选项、目录、资料状态、单独授权、审核文件及审核结果的执行状态 |

## 配置与业务边界

初始课件、往年题、教材和习题保存在数据库，管理员可以修改。分类使用稳定 ID，字段支持文本、整数与选项。年份只是可筛选和分组的整数配置，未知值保留为空，页面不按分类名称分支。

正式安装使用 `business-migrate --modules resources`，同时创建结构和初始分类修订。已有空结构也补齐四类，重复运行保留管理员修改。未启用任何分类时，Web 上传入口说明当前状态。

管理后台从应用会话读取当前配置的学校。后台审核使用管理 API 的角色与学校范围，审核员可以在缺少社区学生资格时处理其有权限的审核事项。

资料版本保存分类修订快照。修改分类后，新提交检查当前配置，既有已发布版本保留原说明。更正或新版本待审时继续交付旧发布版，审核和异步文件发布成功后再切换。

上传默认要求有效校园资格及绑定手机号。下载与预览检查当前内容准入，受限资料另查单独授权、购买或会员权益。管理员例外限制在获准学校范围，全站分类管理使用独立权限。

审核员通过独立权限读取待审文件，读取不激活普通下载引用。普通下架保留已有购买权益的交付判定，安全停用阻止全部下载。申请列表只返回本人的回执，详情从 moderation 读取当前处理结果。

每次上传保存媒体会话，失败先查实际状态。结果未知时保留请求内容和幂等键。本人可撤回待审提案，并删除符合条件的纯草稿或已驳回记录。

ZIP 仅包含当前有权资料。服务端在返回清单、下载分包及写入归档清单前复核当前权限。传输期间撤权时，下载不能生成有效的完整包。

文件预览与下载完成当前权限检查后才支持条件 GET 和单段 Range。Web 上传必选课程，学期与教师可选。标签可通过回车、逗号或失焦逐个添加。

私有 backend 配置固定学校、公开或受限目的与 media profile 的对应关系。启动时核对文件大小、允许类型、学校与保护范围，并确认资料分包限制不超过 media 上限。后台任务和包清理均有批量、超时与重试上限。

## 实际验证

| 环境 | 范围与结果 |
| --- | --- |
| 隔离 PostgreSQL | catalog、moderation、resources、media 与 storage 使用独立运行身份，验证课程关联、上传、待审授权、审核发布、下载、打包、下架及撤权 |
| 媒体与资料回归 | 覆盖并发发布冲突与封禁后的临时引用清理、恢复时新建独立引用，以及文件条件请求前的当前权限复核 |
| 浏览器夹具 | Web 与 Admin 覆盖八语言桌面与移动视口，验证配置字段、上传、重试、审核、申请、目录及分包。中文桌面与阿拉伯语移动截图已复核 |
| v0.1.28 隔离组合 | 验证 Web 实际上传、待审文件拒绝普通下载、Admin 审核、两个独立账号副本及逐字节回读 |
| 正式应用入口的业务联调 | 使用合成身份、PostgreSQL 和 BHpan 协议夹具，验证重启保留资料与会话，资格撤销后禁止下载 |
| 生产 | 迁移读回四个初始分类及其修订。v0.1.31 的资料路径、发布制品及响应头已做上线探测 |

隔离组合的文件传输使用合成文件及 BHpan 协议夹具。当前生产组件与源码提交见[正式工作区锁](https://github.com/StuHelper/stuhelper/blob/v0.1.31/workspace.lock.json)。统一登录与资格撤销验收见[框架实施](framework-bootstrap.md#统一业务组合验收)。

## 交付与剩余范围

生产已启用资料模块。获准账号的正式上传、审核、发布、下载和撤权需要实测，其他语言的译文仍需母语审阅。

资料解锁、会员覆盖及退款具备组合实现。生产仅启用账务管理。定价和交易入口按部署能力开放，真实支付与退款待验收。

受限资料解锁前的文件结构摘要，包括页数、归档文件名及完备度，以及解锁后的标注纠错仍待实现。贡献奖励、在线阅读、个性化标记和应用层加密继续延期。

修订后的作品授权条款已定稿，随下次发行切换。历史同意记录随原资料保存。适用规则见[原创授权政策](../spec/resource-sharing.md#已确认的原创授权政策)。

站内资料投诉证据的结案时间和结案满 12 个月后的到期清理待接入。期限见[数据保留与删除](../spec/data-retention.md)。

相同内容复用、本人免上传和迁移已有隔离数据库回归。按服务身份、保护条件、摘要、长度及副本策略分组。跨用户仍需实际上传验证，之后可共用同范围副本。旧对象保留原标识，历史对象尚未批量合并。

宿主已定时清理过期下载包快照。已完成任务、投诉限流窗口及已确认投递详情有分批清理端口，周期接入待完成。搜索历史与墓碑到期清理待实现。期限见[数据保留与删除](../spec/data-retention.md)。
